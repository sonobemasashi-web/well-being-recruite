ENVIRONMENT

Well-beingなDHになれる環境

1. MTMに特化した研修講師から直接指導が毎月受けられる

メディカルトリートメントモデル（MTM）とは、患者ごとのリスク診査・診断に基づいた、予防医療システムのことです。ただのクリーニング屋さんではない、医療プロフェッショナルとしての歯科衛生士として、患者だけではなく、その家族や地域の健康を支援できるとてもやりがいのあるシステムです。

予防歯科の第一線で活躍する研修講師（オーラルケアサロン Lycka 前田奈美先生）から、MTMの理念と実践を毎月直接学べます。

2. 小児予防管理をスクール型でエンタメ化

小児予防歯科は子どもの健康習慣づくりが大切です。今までの歯科医院の「こわい場所」ではなく、「通いたくなる楽しい場所」にするエンターテインメント型の小児予防歯科を実践しています。子どもたちが楽しく通える仕組み「Well-bee club」をぜひ、一度見学しに来てください。

3. 多職種連携チームだからたくさん学べる環境

  • ・毎週、症例検討会があり、DrやTCと一緒に学べる
  • ・保育士や管理栄養士と子供の発達や栄養指導が学べる
  • ・ガミースマイル、点滴療法など最先端の美容・予防医療が学べる
  • ・TC（トリートメント・コーディネーター）から、カウンセリングを学べる

新卒の方へ

歯科衛生士として、最高のスタートを切れる環境を用意しています。一から丁寧に育てる文化が根付いており、先輩DHが親身にサポートします。

  • ✓ 担当制で先輩DHが1対1でサポート
  • ✓ 1年間のオンボーディングプログラムで着実にスキルアップ
  • ✓ MTMの基礎から実践まで研修講師が毎月指導
  • ✓ 国家試験後すぐ活躍できる研修カリキュラム
YouTubeで視聴する

中途（1〜3年）の方へ

ある程度の経験を持ちながらも、もっと成長したい・予防歯科を深く学びたいという方を歓迎します。既存スキルを活かしつつ、MTMや小児予防歯科の専門性を身につけられます。

  • ✓ 前職の経験を尊重したオーダーメイドの成長プラン
  • ✓ 予防歯科・MTMの専門スキルを集中的に習得
  • ✓ 給与は経験・スキルを考慮して設定
  • ✓ チームに溶け込みやすい雰囲気・丁寧なオンボーディング

経験者（5年以上）の方へ

当院では経験豊富なDHを大歓迎しています。これまでのキャリアを活かしながら、最新のMTM手法や予防歯科の最前線を学べます。

  • ✓ 給与は経験・スキルで加算
  • ✓ 独立した患者さんを担当できる環境
  • ✓ 専門性を深められるセミナー・学会参加サポート
  • ✓ キャリアアップのパスを一緒に考える

ブランク復帰の方へ

育児・介護・留学など、さまざまな理由でブランクがある方も大歓迎です。丁寧なウォームアップ期間を設けているので、安心して復帰できます。

  • ✓ ブランク期間に関わらず歓迎・スキル確認から始める
  • ✓ 短時間勤務・パート勤務からの相談も可能
  • ✓ 先輩DHによるマンツーマンフォロー
  • ✓ 無理のないペースで現場復帰をサポート
